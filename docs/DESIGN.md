# File Bridge 3.0：单主机公网网站

## 运行方式

浏览器 → Cloudflare 公网入口 → cloudflared → 主机回环网站 → 主机磁盘。主机上仅运行一个应用实例，由一个监督进程分别维护网站和隧道进程。访问者只需打开同一个完整网址。

已移除 2.0 的设备身份、配对码、OPAQUE、设备记忆、双向设备心跳、公共 MQTT/WSS 中继、远程要求另一台设备打开网页、Electron 窗口和托盘。当前应用无 npm 运行依赖。

## 可恢复上传

浏览器先在 IndexedDB 保存任务与 File/Blob。文件以 1 MiB 为单位逐块计算摘要，提交分块清单与清单摘要；计算时不会一次性读入整个 1 GB 文件。主机落盘上传记录，逐块落盘、校验、确认。

恢复时重新读取并校验主机上的分块。缺失或损坏的块重新上传，合法已确认块跳过。同内容、同名称的文件复用上传记录，支持临时隧道换地址后重新选择相同文件续传。浏览器本地任务仍受网站 origin 隔离，完整的刷新后自动恢复体验需要保持同一域名。

提交完成时，主机按清单重读分块并组装文件，验证块和总长度，生成整文件摘要。组装文件同步到磁盘，再重命名，最后原子保存最近内容清单。中断后可重复提交；确定性文件路径与任务编号防止重复内容记录。文字也使用持久的最近内容清单按请求编号去重。近期去重窗口与最近内容保留窗口一致，为 24 小时；上传记录保留 7 天。

## 监督与隧道

网站与 cloudflared 各自重试，间隔线性增加到 30 秒，稳定后重置。网站连续三次本地健康检查失败时重启。网络暂时故障交由 cloudflared 内部重连；其本地 metrics/readiness 接口用于记录状态，不把日志中出现网址当成连接成功。

临时隧道退出后立即撤销旧的 current-url，新的地址写入后再提供。命名隧道使用用户已有配置与固定域名。主机默认回环监听，控制接口使用独立本地控制凭据；公网访问凭据不能调用主机控制接口。

明确停止会取消重试并终止本实例子进程。当前用户登录自启为可选功能，不安装系统服务，不重新启动计算机。监督进程自身被结束后由明确启动或登录自启恢复，不声称能在自身不存在时自行运行。

## 数据与隐私

默认运行目录为 var，可显式设置绝对 profile 路径；不同实例彼此隔离。最近文件和文字保留 24 小时，归档长期保存；上传分块和上传记录保存 7 天。队列完成后删除浏览器中的文件副本，保留最近 20 项完成记录。下载使用 attachment 并支持 Range；受限图片格式单独提供预览。

源码仓库排除运行状态、访问令牌、上传内容、日志及 Cloudflare 凭据。写入使用同步和原子重命名；Linux 同步目录，Windows 不把目录 fsync 伪称为可用保证。硬件、文件系统、磁盘空间和公共隧道依然构成真实可用性边界。
